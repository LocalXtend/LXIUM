# 애드온 모음 (catalog.json)

**애드온 모음**은 모드를 어디서 받을지 적어 둔 JSON 파일입니다.
모음 주소를 런처 설정에 넣으면, 그 모음의 모드가 모드 패널의 **모드 추가하기**에 나오고, 새 버전이 나오면 업데이트할 수 있습니다.

## 쓰는 사람

1. 런처 오른쪽 위 톱니(설정) → **애드온 모음**에 `https://`로 시작하는 주소를 넣고 **추가**를 누릅니다.
2. 게임 카드를 누르고 **모드** 칸 → **모드 추가하기**에서 원하는 모드의 **추가**를 누르면 받아 둡니다. 설치는 그다음 **설치**로 따로 합니다.
3. 추가한 모드에 새 버전이 나오면 라이브러리 카드에 "업데이트 있음"이 뜹니다.
4. 공식 모음만 남기고 싶으면 **기본값으로 되돌리기**를 누릅니다.

> 모드는 게임 안에서 실행되는 프로그램입니다. **믿을 수 있는 사람이 만든 모음만 추가하세요.**
> 런처는 받은 파일이 모음·GitHub에 적힌 것과 똑같은지(SHA-256) 확인하지만, 모드를 만든 사람이 나쁜 파일을 올리는 것까지는 막지 못합니다.

## 모음 만드는 사람

모음은 아래 모양의 JSON 파일 하나입니다. `https://`로 받을 수 있는 곳(GitHub 저장소의 raw 주소 등)에 올리면 됩니다.

```json
{
  "schema": 2,
  "name": "내 모음",
  "addons": [
    { "github": "내계정/LXIUM_내게임" }
  ]
}
```

모드를 적는 방법은 세 가지입니다.

**1. GitHub 저장소 (가장 쉬움, 추천)**
`{ "github": "계정/저장소" }` 한 줄이면 됩니다. 런처가 그 저장소의 릴리스를 직접 읽어서 **새 버전을 내면 모음을 고치지 않아도** 런처에 나옵니다.
저장소는 [애드온 규격](addon.md)대로 만들고, 릴리스는 이렇게 올립니다.
- 태그: `<id>-v<버전>` (예: `LXIUM_manosaba-v0.8.0`)
- 파일: `<id>-<버전>.zip`
- 그 태그의 저장소 루트에 `lxium.json`(필수)과 `addon.png`(아이콘, 선택)

**2. 외부 모드 (LXIUM 규격이 아닌 남의 모드)**
남이 만든 모드의 GitHub 릴리스 zip에서 필요한 파일만 골라 쓰는 방법입니다. 예를 들어 어떤 모드의 릴리스 zip에 BepInEx 전체가 들어 있어도, `include`에 `BepInEx/plugins/그모드/`만 적으면 런처는 그 폴더만 가져옵니다 (BepInEx는 런처가 따로 관리).
외부 모드는 그 모드 제작자의 동의를 받은 뒤 등록하세요.
`asset`(파일 이름 규칙), `include`(가져올 폴더), `manifest`(이름·게임·로더 정보)를 적습니다. 자세한 모양은 AI용 문서를 보세요.

**3. 고정 주소**
`url`(zip 주소)·`sha256`·`manifest`를 직접 적습니다. 버전마다 항목을 하나씩 더해야 합니다. SHA-256은 PowerShell에서 `(Get-FileHash 파일.zip).Hash`로 구합니다.

## 공식 모음 (개발자)

LXIUM 저장소 루트의 `catalog.json`입니다. 모드 저장소 목록이라 **모드를 릴리스해도 고칠 필요가 없습니다.**
새 게임 모드 저장소를 만들었거나 외부 모드를 등록할 때만 고칩니다.
