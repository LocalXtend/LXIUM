# 애드온 모음 (catalog.json)

**애드온 모음**은 여러 애드온을 한 번에 알려 주는 JSON 파일입니다.
모음 주소를 런처 설정에 넣으면, 그 모음의 애드온을 런처에서 바로 받고 새 버전이 나오면 업데이트할 수 있습니다.
다른 사람이 만든 애드온도 이렇게 나눌 수 있습니다.

## 쓰는 사람

1. 런처 오른쪽 위 톱니(설정) → **애드온 모음**에 `https://`로 시작하는 주소를 넣고 **추가**를 누릅니다.
2. 게임을 열면 모음의 애드온이 "받기" 표시와 함께 버전 목록에 나옵니다. **받아서 설치**를 누르면 받고 바로 설치합니다.
3. 설치한 애드온에 새 버전이 나오면 라이브러리 카드에 "업데이트 있음"이 뜹니다.

> 애드온은 게임 안에서 실행되는 프로그램입니다. **믿을 수 있는 사람이 만든 모음만 추가하세요.**
> 런처는 받은 파일이 모음에 적힌 것과 똑같은지(SHA-256) 확인하지만, 모음을 만든 사람이 나쁜 파일을 올리는 것까지는 막지 못합니다.

공식 모음은 처음부터 들어 있습니다. 필요 없으면 휴지통 버튼으로 뺄 수 있습니다.

## 모음 만드는 사람

모음은 아래 모양의 JSON 파일 하나입니다. 인터넷에서 `https://`로 받을 수 있는 곳(GitHub 저장소의 raw 주소 등)에 올리면 됩니다.

```json
{
  "schema": 1,
  "name": "내 모음",
  "addons": [
    {
      "url": "https://example.com/My_mod-1.0.0.zip",
      "sha256": "zip 파일의 SHA-256 (64자)",
      "manifest": { "zip 안 lxium.json 내용을 그대로": "" }
    }
  ]
}
```

- `addons`의 항목 하나 = 애드온 zip **한 버전**입니다. 옛 버전도 남겨 두면 사용자가 골라서 설치할 수 있습니다.
- zip은 [애드온 규격](addon.md)대로 만듭니다.
- `url`은 반드시 `https://`, `sha256`은 반드시 적어야 합니다. 빠지면 런처가 그 항목을 무시합니다.
- SHA-256은 PowerShell에서 `(Get-FileHash 파일.zip).Hash`로 구할 수 있습니다.
- zip을 바꾸면 SHA-256도 바뀝니다. 올린 zip과 모음의 값이 다르면 런처가 받기를 거부합니다.

## 공식 모음 올리는 법 (개발자)

1. 모드 프로젝트를 빌드하고 저장소 루트에서 `./build.ps1`을 실행합니다. `dist/catalog.json`이 만들어집니다.
2. GitHub에 `<id>-v<버전>` 릴리스를 만들고, `build.ps1`이 쓴 그 zip을 올립니다.
3. `dist/catalog.json`을 저장소 루트 `catalog.json`으로 옮겨 커밋합니다. 옛 버전 항목은 지우지 않고 새 항목을 더합니다.
