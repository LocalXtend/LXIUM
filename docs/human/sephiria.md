# 세피리아 분석

세피리아 최적화 모드(`optimizeMods/LXIUM_sephiria/`)를 만들기 전에 게임이 어떻게 생겼는지 조사한 결과입니다.
게임을 실행하거나 파일을 바꾸지 않고, 설치된 파일을 읽어서만 분석했습니다.

> 정확한 사실 목록과 근거는 AI용 문서 [`../ai/sephiria.md`](../ai/sephiria.md)에 있습니다. 두 문서는 항상 같이 고칩니다.

## 한 줄 결론

**게임에 들어 있는 공식 모드 로더로 모드를 올리고, 최적화는 실행 중에 설정을 바꾸거나 Harmony로 패치합니다.**
BepInEx·MelonLoader는 설치하지 않고, 게임 파일도 고치지 않습니다.

## 게임은 어떻게 생겼나

- Unity 6 엔진, Mono 방식입니다. C# 코드가 `Sephiria_Data/Managed/Assembly-CSharp.dll`에 그대로 들어 있어서 분석하기 쉽습니다.
- 화면은 Unity의 2D 전용 렌더러(URP 2D)로 그립니다. 2D 조명(`Light2D`)을 많이 쓰고, 화면 후처리와 날씨 효과(비·눈·안개)가 있습니다.
- 게임 안 그래픽 옵션은 **해상도, VSync, FPS 제한뿐**입니다. 렌더링 품질을 낮추는 옵션이 없어서, 사양이 낮은 PC에서는 최적화 모드가 할 일이 있습니다.
- 투사체·이펙트 재사용(풀링), 화면 밖 애니메이션 생략 같은 기본 최적화는 이미 되어 있습니다.

## 공식 모드 API (HorayModAPI)

게임 개발사(Team Horay)가 넣어 둔 모드 시스템입니다. 공식 문서: https://teamhoray.com/mod-api (아직 작업 중 표시)

**모드를 넣는 방법**

```
게임폴더/
└─ AddOns/
   └─ 모드이름/
      ├─ metadata.json   ← 이름, 버전, 제작자, DLL 파일, 시작 클래스
      └─ 모드.dll
```

타이틀에서 세이브를 골라 게임에 들어가는 순간, 게임이 `AddOns` 안의 폴더를 하나씩 열어 DLL을 불러오고 `HorayModBase`를 상속한 클래스를 찾아 실행합니다.
게임 데이터가 준비되기 전에 불러오므로 모드가 끼어들 시간은 충분합니다.
다만 **타이틀 화면에서는 아직 모드가 없는 상태**라서, 최적화도 게임에 들어간 뒤부터 적용됩니다.

**할 수 있는 것**

- 아이템, 무기, 기적, 상태이상, 코스튬 등을 추가하거나 고치기
- 게임 시작, 층 생성, 회피, 디버프 같은 순간에 알림 받기
- 다국어 텍스트 추가

**할 수 없는 것**

- 그래픽·성능 관련 기능은 없습니다. 그래서 공식 API는 "모드 코드를 게임 안에서 실행시켜 주는 입구"로만 씁니다.
  실제 최적화는 그 안에서 Unity 설정을 직접 바꾸거나 Harmony로 게임 코드를 고쳐서 합니다.

**알아 둘 점**

- `Libs/` 같은 하위 폴더의 DLL은 게임이 찾아주지 않습니다. 그래서 기존 모드들은 작은 시작용 DLL을 하나 더 두거나, 코드에서 직접 불러옵니다.
- 모드가 있으면 게임이 이를 감지하지만, 하는 일은 오류 보고 업로드를 끄는 것뿐입니다. 막지 않습니다.
- Steam 창작마당은 언어팩에만 쓰이고, DLL 모드는 `AddOns` 폴더로만 들어옵니다.

## 지금 쓰이는 커뮤니티 모드

조사한 PC에 있던 모드 4개(CustomSkin, Mira's Item Mod, Sephiria QoL, SendMoney)는 **모두 AddOns 방식**이었습니다.
그중 3개가 Harmony를 각자 들고 왔는데, 버전이 2.10.2와 2.4.2로 섞여 있습니다.
그래서 우리 모드는 이미 불려 온 Harmony가 있으면 그걸 같이 쓰고, 없을 때만 우리 것을 불러옵니다.

## 왜 다른 방법은 안 쓰나

| 방법 | 안 쓰는 이유 |
|---|---|
| BepInEx / MelonLoader | 게임 폴더에 로더 파일을 추가해야 하고, 둘을 같이 깔면 충돌할 수 있습니다. 이 게임 모드들은 전부 공식 로더를 쓰니 굳이 로더를 하나 더 얹을 이유가 없습니다 |
| 게임 DLL 직접 수정 | Steam 업데이트나 파일 검사 한 번에 원래대로 돌아갑니다. 다른 모드가 고치는 부분이 바뀌어 같이 깨질 수 있고, 수정한 게임 파일을 배포하는 건 저작권 문제가 있습니다 |
| 실행 옵션 (`-force-d3d12` 등) | 이건 씁니다. 파일을 안 바꾸고 런처가 실행할 때 붙이기만 하면 됩니다. 효과는 측정해 보고 정합니다 |

멀티플레이 접속할 때 게임은 버전 문자열만 비교합니다. 그래도 데미지나 판정 같은 게임 규칙을 바꾸면 친구와 화면이 어긋날 수 있으니, 최적화 모드는 게임 규칙을 건드리지 않습니다.

## 모드 만들 때 지킬 것

1. 설치 위치는 `AddOns/LXIUM_sephiria/`입니다. 애드온 규격(`addon.md`)의 `none` 변형으로 배포합니다.
2. `metadata.json`에는 게임이 읽는 다섯 항목(`modName`, `modVersion`, `modAuthor`, `dllFile`, `entryClass`)만 씁니다.
3. 최적화는 먼저 설정 바꾸기(렌더 해상도 비율, 조명·후처리·날씨 끄기)로 하고, 그래도 부족할 때만 Harmony 패치를 씁니다.
4. 다른 모드가 먼저 또는 나중에 불려 온다고 가정하지 않습니다. 순서가 정해져 있지 않습니다.
5. 로그는 `[LXIUM]`으로 시작합니다. 게임 로그 파일(`Player.log`)에 남습니다.

## 실제로 재 보니

진단 모드(`LXIUM_sephiria` 0.1.0~0.1.1)를 넣고 내장 그래픽 노트북에서 마을과 초반 층을 플레이해 측정했습니다. 다른 모드 4개가 함께 설치된 상태였습니다.

**게임 설정값**

- 렌더 해상도 비율 1(화면 그대로), 안티에일리어싱 꺼짐, HDR 켜짐
- 2D 조명용 텍스처도 화면 해상도 그대로 그립니다.
- 화면 후처리(색 보정 등)는 켜져 있고, 후처리 설정을 매 프레임 다시 계산합니다.
- FPS 제한이 기본으로 꺼져 있어서, 가벼운 장면에서는 필요 이상으로 많이 그립니다(노트북 발열·배터리).

**프레임**

- 평균 FPS는 118~165로 충분합니다.
- 그런데 게임 안에 있는 동안 **약 0.5초마다 한 번씩 25~37ms로 멈칫합니다**(평소 5~7ms). 전투가 몰리면 더 잦아집니다.
  평균 FPS가 높아도 느껴지는 "끊김"은 이쪽일 가능성이 큽니다.

**원인 좁히기 (2차 측정)**

- **메모리 정리(GC) 때문은 아닙니다.** 멈칫한 프레임 386개 중 GC가 같이 돈 건 8개뿐이었습니다.
- **그래픽카드 부담 때문도 아닙니다.** 렌더 해상도를 절반(픽셀 1/4)으로 낮춰도 FPS가 그대로였습니다(207 → 205).
  그래서 해상도나 조명 품질을 낮추는 최적화는 이 PC에서는 효과가 작습니다. 병목은 CPU 쪽입니다.
- 남은 후보는 게임 안에서 일정한 간격으로 도는 CPU 작업이었습니다.

**원인은 게임이 아니라 다른 모드 (3차 측정)**

다른 모드 4개를 빼고 LXIUM만 넣은 채 같은 곳을 플레이했더니, 0.5초마다 오던 멈칫이 사라졌습니다.
상위 1% 프레임이 30~37ms에서 7~10ms로 줄었고, 멈칫은 층 이동처럼 로딩하는 순간에만 남았습니다.
즉 **게임 자체는 매끄럽고, 끊김은 다른 모드가 만든 것**입니다.

코드를 살펴보면 Sephiria QoL이 가장 유력합니다. 기능 60여 개를 1/6초·1초·2초 간격으로 계속 돌리는 구조이고,
그중 일부는 화면 전체에서 오브젝트를 찾는 무거운 작업을 합니다.
다만 아직은 추정이라, 모드를 하나씩 넣어 보며 확정합니다.
QoL에는 자체 측정 명령(`/qol perf on`, `/qol perf show`, `/qol perf off`)도 있어서 어느 기능이 무거운지 볼 수 있습니다.

**다른 모드와 단축키**

측정용으로 F9를 썼더니 CustomSkin 모드의 스킨 캡처(F9)가 같이 실행됐습니다.
CustomSkin은 F7·F9, Mira's Item Mod는 F1~F3, QoL은 PageUp/PageDown·방향키 등을 씁니다.
그래서 LXIUM은 기본 단축키를 두지 않습니다.

## 아직 모르는 것

- 0.5초마다 멈칫하게 만드는 모드가 정확히 어느 것인지.
- 후반 층이나 고해상도 전체 화면처럼 무거운 장면에서도 그래픽카드가 병목이 아닌지.

## 게임이 업데이트되면

AI용 문서 2장의 값(빌드 번호, DLL 해시)을 새 버전과 비교합니다. 다르면 이 문서 내용 중 바뀐 부분이 있는지 다시 확인합니다.
