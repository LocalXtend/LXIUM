# LXIUM 런처

게임에 BepInEx·MelonLoader 모드를 설치·제거하고, 모드 설정을 바꾸고, 애드온 모음에서 모드를 받아 업데이트하는 프로그램입니다.
설치 없이 압축만 풀어서 씁니다.

## 쓰는 법

1. `LXIUM-<버전>-portable.zip`을 원하는 곳에 풀고 `LXIUM.exe`를 실행합니다.
2. 라이브러리에 모드가 있는 게임이 카드로 나옵니다. 게임은 Steam 라이브러리 폴더를 모두 뒤져서 찾습니다.
3. 게임 카드를 누르면 자세한 화면이 열립니다.
   - 게임 정보 (Steam 상점: 설명, 장르, 출시일, 개발·배급사)
   - 게임 폴더, 게임 실행 버튼
   - 게임에서 찾은 모드 로더. 여러 개면 모드를 설치할 로더를 고릅니다.
   - 모드 목록: 설치·업데이트·제거, 버전이 여러 개면 버전 고르기
4. 제거하면 모드가 덮어쓴 원래 파일까지 되돌립니다. 모드 설정 파일은 남습니다.

## 모드 버전과 호환

- 같은 모드의 버전이 여러 개면 **버전** 목록에서 골라 설치할 수 있습니다. 옛 버전으로 되돌리기도 됩니다.
- "받기"라고 적힌 버전은 아직 받지 않은 것입니다. **받아서 설치**를 누르면 애드온 모음에서 받은 뒤 설치합니다.
- 고른 버전이 지금 게임의 로더와 맞지 않으면 빨간 글씨로 알려 줍니다. (예: "BepInEx 6 6.0.0-be.800 이상 권장")
- 설치한 모드에 새 버전이 나오면 라이브러리 카드에 **업데이트 있음**이 뜹니다.

## 모드 로더

BepInEx 5·6, MelonLoader도 런처가 설치·제거합니다.

- 로더가 없으면 모드 로더 칸에 설치 버튼이 나옵니다. 모드 설치를 눌러도 필요한 로더부터 설치할지 묻습니다.
- 로더는 공식 배포처(GitHub, builds.bepinex.dev)에서 게임에 맞는 최신판(64/32비트, IL2CPP/Mono)을 받습니다.
- 로더를 설치한 뒤 게임을 한 번 실행하면 로더가 처음 준비를 마칩니다.
- 로더를 제거하면 그 로더 폴더 안의 다른 모드와 설정도 함께 지워집니다. 제거 전에 지울 항목을 보여 줍니다.

## 모드 설정

설치된 모드의 **설정** 버튼, 모드 로더 칸의 **로더 설정** 버튼으로 설정을 바꿉니다.

- 켬/끔은 **활성화/비활성화** 버튼, 정해진 선택지는 목록, 범위가 있는 숫자는 **슬라이더**(옆에 값 입력칸), 그 밖은 직접 입력합니다.
- 각 항목의 설명과 기본값이 함께 나옵니다.
- 바꾼 설정은 게임을 다시 시작하면 적용됩니다. 설정 파일은 모드가 처음 실행될 때 만들어지므로, 설치 직후에는 게임을 한 번 실행하세요.

## 런처 설정 (오른쪽 위 톱니)

- **업데이트 자동 확인**: 켜 두면 시작할 때 새 LXIUM과 애드온 모음의 새 버전을 확인합니다.
- **지금 업데이트 확인**: 바로 확인합니다. 새 LXIUM이 있으면 머리글에 업데이트 버튼이 생기고, 누르면 받아서 바꾼 뒤 다시 시작합니다.
- **애드온 모음**: 다른 사람이 만든 모음 주소를 추가하거나 뺍니다. 자세한 내용은 [애드온 모음](catalog.md)을 보세요.

### 업데이트해도 남는 것

- 런처 설정(`settings.json`), 받아 둔 애드온(`addons/`)은 런처를 업데이트해도 그대로입니다.
- 모드 설정은 게임 폴더에 있어서 모드를 업데이트하거나 제거해도 지워지지 않습니다.

## Windows 10

Windows 10에서도 쓰도록 Windows 11에만 있는 글꼴·아이콘·효과를 쓰지 않습니다.
다만 .NET 10이 공식으로 지원하는 Windows 10은 기업·IoT용 일부뿐이라, 일반 Windows 10에서 문제가 생기면 Issues에 알려 주세요.
