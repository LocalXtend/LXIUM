# LXIUM 런처

게임에 BepInEx·MelonLoader 모드를 추가·설치·업데이트·제거하고, 모드 설정을 바꾸는 프로그램입니다.
설치 없이 압축만 풀어서 씁니다.

## 처음 실행

1. `LXIUM-<버전>-portable.zip`을 원하는 곳에 풀고 `LXIUM.exe`를 실행합니다.
2. 하얀 화면에서 **Select language**를 눌러 언어를 고르고 **다음 →**을 누릅니다. (한국어, English, 日本語, 简体中文, 繁體中文)
3. 라이브러리에 모드가 있는 게임이 카드로 나옵니다. 게임은 Steam 라이브러리 폴더를 모두 뒤져서 찾습니다.

## 게임 카드

카드의 표지를 누르면 그 위에 세 칸이 나타납니다. 카드 밖으로 마우스를 빼거나 다른 곳을 누르면 사라집니다.

| 칸 | 하는 일 |
|---|---|
| 왼쪽 위 **설정** | 게임 설정 패널: 게임 정보, 게임 폴더, 모드 로더 설치·업데이트·제거·설정 |
| 오른쪽 위 **모드** | 모드 패널: 모드 찾기·추가·설치·업데이트·제거·설정 |
| 아래 **플레이** | 게임 실행 |

## 모드 패널

- **모드 추가하기**: 애드온 모음에서 찾은 모드입니다. **추가**를 누르면 받아 둡니다. (저절로 설치되지 않습니다)
- **추가한 모드**: 추가한 모드를 **설치**·**업데이트**·**제거**합니다. 제거하면 모드가 덮어쓴 게임 파일까지 원래대로 되돌립니다.
- 버전이 여러 개면 **버전**에서 골라 설치하거나 옛 버전으로 되돌릴 수 있습니다.
- 위의 검색 칸과 태그(성능·유틸리티·재미·스토리·msmod)로 모드를 거를 수 있습니다.
- 모드에 맞는 로더가 없으면 로더부터 설치할지 묻고, 먼저 필요한 다른 모드가 있으면 그것부터 설치할지 묻습니다.
- 로더가 서로 부딪치게 깔려 있으면(예: BepInEx와 MelonLoader 함께) 위에 경고가 뜹니다.
- 받기·설치·제거 중에는 진행 상황이 화면 가운데 나옵니다. 멈춘 것이 아닙니다.

## 모드 로더

BepInEx 5·6, MelonLoader를 런처가 설치·업데이트·제거합니다. (게임 설정 패널의 모드 로더 칸)

- 로더는 공식 배포처(GitHub, builds.bepinex.dev)에서 게임에 맞는 최신판(64/32비트, IL2CPP/Mono)을 받습니다.
- **로더 업데이트**는 더 새 판이 있으면 덮어 설치합니다. 설정과 모드는 그대로 남습니다.
- 로더를 설치한 뒤 게임을 한 번 실행하면 로더가 처음 준비를 마칩니다.
- 로더를 제거하면 그 로더 폴더 안의 다른 모드와 설정도 함께 지워집니다. 제거 전에 지울 항목을 보여 줍니다.

## 모드 설정

설치된 모드의 **설정** 버튼, 모드 로더 칸의 **로더 설정** 버튼으로 설정을 바꿉니다.

- 켬/끔은 **활성화/비활성화** 버튼, 정해진 선택지는 목록, 범위가 있는 숫자는 **슬라이더**(옆에 값 입력칸), 그 밖은 직접 입력합니다.
- 모드가 [설정 설명(.lxconfig)](lxconfig.md)을 넣어 두었으면 설명이 런처 언어로 나오고, **게임을 한 번도 실행하지 않았어도** 설정을 바꿀 수 있습니다.
- 바꾼 설정은 게임을 다시 시작하면 적용됩니다.

## 런처 설정 (오른쪽 위 톱니)

- **업데이트 자동 확인**: 켜 두면 시작할 때 새 LXIUM과 모드의 새 버전을 확인합니다.
- **지금 업데이트 확인**: 바로 확인합니다. 새 LXIUM이 있으면 머리글에 업데이트 버튼이 생기고, 누르면 받아서 바꾼 뒤 다시 시작합니다.
- **언어**: 런처 언어를 바로 바꿉니다.
- **애드온 모음**: 모음 주소를 추가·빼기, **기본값으로 되돌리기**로 공식 모음만 남깁니다. ([애드온 모음](catalog.md))

### 업데이트해도 남는 것

- 런처 설정(`settings.json`), 추가한 모드(`addons/`)는 런처를 업데이트해도 그대로입니다.
- 모드 설정은 게임 폴더에 있어서 모드를 업데이트하거나 제거해도 지워지지 않습니다.

## 다른 언어 더하기

`lang/` 폴더의 `ko.json`을 복사해 `<언어 코드>.json`으로 저장하고 오른쪽 글을 번역하면 언어 목록에 나옵니다. `{0}` 같은 자리 표시는 그대로 둡니다. `_name`은 그 언어로 쓴 언어 이름입니다.

## Windows 10

Windows 10에서도 쓰도록 Windows 11에만 있는 글꼴·아이콘·효과를 쓰지 않습니다.
다만 .NET 10이 공식으로 지원하는 Windows 10은 기업·IoT용 일부뿐이라, 일반 Windows 10에서 문제가 생기면 Issues에 알려 주세요.
