# 세피리아 렌더링 최적화 설계

게임이 원래 그리는 방식에서 멈추지 않고, 저사양 내장 그래픽(Intel UHD 620급)에서도 부드럽게 돌도록 LXIUM만의 렌더링 기능을 만드는 계획입니다.

> 정확한 근거와 기술 목록은 AI용 문서 [`../ai/sephiria-render.md`](../ai/sephiria-render.md)에 있습니다. 두 문서는 항상 같이 고칩니다.

## 출발점

- 세피리아는 Unity의 2D 렌더러로 그리고, 카메라는 하나입니다.
- 화면 크기로 보면 **640×360 픽셀아트**를 확대해 보여 주는 게임으로 보입니다. 1080p 화면이면 딱 3배입니다.
- 개발 PC(창 모드)에서는 그래픽카드가 병목이 아니었습니다. 하지만 더 약한 그래픽, 전체 화면 고해상도에서는 다를 수 있어서 다시 잽니다.

## 만들 기능 후보

**A. 게임에 이미 있는 장치를 조합하기 (안전)**

| 기능 | 하는 일 |
|---|---|
| 공간 해상도 | 게임 화면을 낮은 해상도로 그린 뒤, AMD FSR로 키우면서 선명하게 다듬습니다. |
| 픽셀 정렬 해상도 | 픽셀아트 원본 해상도(360·720줄)로 그린 뒤 그대로 정수배 확대합니다. 픽셀아트는 거의 그대로 보이면서 그릴 픽셀 수가 최대 1/9로 줄어듭니다. 세피리아 전용 아이디어입니다. |
| 조명 해상도 | 2D 조명을 절반·1/4 해상도로 계산합니다. 조명은 부드러운 빛이라 차이가 잘 안 보입니다. |
| 덮개 레이어 정리 | 화면 전체를 덮는 반투명 안개·어둠·날씨 효과 중 사실상 안 보이는 것은 그리지 않고, 저사양에서는 줄입니다. |
| 후처리 단계 | 저사양에서는 HDR과 화면 후처리를 끕니다. |
| 프레임 페이싱 | 노트북이 과열로 느려지지 않게 프레임 상한을 둡니다. |

**B. LXIUM이 직접 그리는 방식 (도전)**

| 기능 | 하는 일 |
|---|---|
| 월드/HUD 분리 | 게임 세계만 낮은 해상도로 그리고, 체력바·글자 같은 HUD는 원래 해상도로 그립니다. |
| 2D 재투영(프레임 생성) | 게임 세계를 한 프레임 걸러 그리고, 사이 프레임은 직전 그림을 카메라가 움직인 만큼 밀어서 만듭니다. 2D 카메라라 배경은 정확히 맞지만, 움직이는 적·탄환은 반 박자 늦게 보일 수 있어 선택 기능으로 둡니다. |

**C. 전용 셰이더** — A·B 결과를 본 뒤 결정합니다. 게임과 같은 버전의 Unity 에디터가 필요합니다.

**하지 않는 것**

- 드로우 콜 일괄 처리: 이미 충분히 적게 그리고 있습니다.
- 엔티티 병렬 처리: 게임과 멀티플레이 상태가 한 스레드에서만 안전하게 돌아서, 나누면 충돌·동기화 문제가 납니다.

## 어떻게 확인하나

1. LXIUM에 **렌더 실험실**을 넣습니다. 게임에 들어가 20초 뒤부터 후보 설정을 8초씩 하나씩 켜 보며 프레임과 스크린샷을 남기고, 끝나면 원래대로 돌립니다.
2. 실제 플레이처럼 **전체 화면**에서 잽니다.
3. 스크린샷으로 HUD가 선명한지, 픽셀아트가 깨지지 않는지 봅니다.
4. 효과가 확인된 것만 기능으로 만들고 설정으로 켜고 끌 수 있게 합니다. 기본으로 켜는 건 화질 손실이 없는 것만입니다.

## 아직 모르는 것

- FSR 같은 업스케일러가 게임 빌드에 실제로 들어 있는지
- HUD가 어떤 방식으로 그려지는지
- 실제 UHD 620 장비에서의 성능 (지금은 장비가 없습니다)
