# 세피리아 렌더링 최적화 설계

게임이 그리는 방식을 그대로 두지 않고, 내장 그래픽(Intel UHD 620 ~ Iris Xe)에서도 전투 중 120 fps 이상 나오도록 LXIUM만의 렌더링 방식을 만드는 계획입니다. HUD·메뉴·글자는 항상 원래 해상도로 둡니다.

> 정확한 근거와 기술 목록은 AI용 문서 [`../ai/sephiria-render.md`](../ai/sephiria-render.md)에 있습니다. 두 문서는 항상 같이 고칩니다.

## 출발점

세피리아는 **픽셀 아트**를 직교 카메라로 그립니다. 픽셀 아트는 그림 자체의 해상도(텍셀)가 화면보다 훨씬 낮아서, 화면 해상도로 그려도 정보가 늘지 않습니다. 이 점을 이용하는 것이 계획의 중심입니다. 다만 어디가 병목인지 모르는 채로 고치지 않기 위해 **먼저 잽니다**.

## 지금 버전 (0.1.0): 재는 도구 + 첫 설정

| 기능 | 하는 일 |
|---|---|
| 프레임 통계 | 10초마다 fps와 함께, 한 프레임 시간이 어디에 쓰였는지(GPU 대기 / 스크립트 / 렌더 제출) 로그에 남김 |
| 렌더 상태 덤프 (F9) | 지금 장면의 카메라·조명·블룸·그려지는 것·UI·스크립트 수를 파일로. 장면이 바뀌면 자동 |
| 설정 비교 (F10) | 조명 해상도·월드 해상도 설정을 차례로 바꿔 fps를 재고 스크린샷을 남김. 끝나면 원래대로 |
| 조명 해상도 | 2D 조명을 화면보다 낮은 해상도로 (설정에서 선택, 기본은 게임 값) |
| 월드 해상도 | 월드만 낮은 해상도로 그리고 화면으로 확대 (UI는 그대로, 기본은 게임 값) |

게임 코드는 전혀 고치지 않습니다 (Harmony도 안 씀). 결과는 게임 폴더 `AddOns/LXIUM_sephiria/logs/`에 남습니다.

## 앞으로 만들 LXIUM 렌더 (후보)

| 기능 | 하는 일 | 힌트 |
|---|---|---|
| 텍셀 격자 렌더 | 월드를 "픽셀 아트 해상도 × 2~3배"로만 그리고, 픽셀이 또렷하게 남는 전용 확대 셰이더로 화면에 올림. 조명·빛 번짐·안개도 그 해상도로. 화면 픽셀 수가 1/4~1/9로 | 공간 해상도 |
| 직교 이동 재투영 | 두 프레임 중 한 번만 월드를 그리고, 사이 프레임은 지난 그림을 카메라가 움직인 만큼 밀어서 보여 줌. 2D 직교 카메라라 멈춘 배경은 정확히 맞음. UI는 매 프레임 그림. 움직이는 적은 반 프레임률. GPU가 버거울 때만 켬 | 프레임 재투영 |
| 정적 층 캐시 | 방에 들어갈 때 바닥 타일·배경을 한 장으로 구워 두고, 매 프레임은 그 한 장에 조명만 곱함. 타일 수천 장 → 한 장 | 불투명 얼음 |
| 화면 층 합치기 | 안개·분위기·비·눈을 한 번에 그림 | 렌더 패스트 |
| 보이는 것만 갱신 | 화면 밖 캐릭터·이펙트·조명 애니메이션은 쉬게 함 | 비동기(병렬 대신 일 줄이기) |
| 할당 없애기 | 매 프레임 생기는 작은 메모리 할당을 없애 끊김(GC) 줄이기 | — |
| 해상도 조절기 | 목표 프레임을 못 맞추면 월드 해상도를 자동으로 내리고, 여유 있으면 올림 | 공간 해상도 |

**전용 셰이더**도 만듭니다: 픽셀 아트 확대(선명화 포함), 가벼운 스프라이트 조명, 안개·날씨 합치기, 정적 층 합성, 가벼운 점 조명. 셰이더는 게임 안에서 컴파일할 수 없어서, 이 저장소의 다른 게임(마법소녀의 마녀재판)에서 쓴 방식(게임 셰이더를 틀로 삼아 코드만 바꿔 넣기)을 씁니다. 이 작업에는 UnityPy 설치가 필요합니다.

## 쓰는 법 (0.1.0)

1. 게임을 켜고 타이틀, 마을, 던전 전투, 보스, 비·눈 오는 곳에 가 봅니다
2. 각 장면에서 가만히 서서 **F10** → 약 1분 동안 화면 해상도가 바뀌며 비교합니다 (다시 누르면 중단)
3. 필요하면 **F9**로 그 자리의 상태를 저장합니다
4. `AddOns/LXIUM_sephiria/logs/` 폴더와 `%USERPROFILE%\AppData\LocalLow\TEAMHORAY\Sephiria\Player.log`를 확인합니다

설정 파일 `AddOns/LXIUM_sephiria/settings.json`은 처음 실행할 때 만들어집니다. 키와 비교할 설정 목록을 바꿀 수 있습니다.
