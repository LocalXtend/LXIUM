# LXIUM 디자인 규칙

런처 화면을 고치거나 새 화면을 만들 때 따르는 규칙과, **왜 그렇게 정했는지**입니다.
이유를 읽고 지금도 맞으면 규칙을 따르고, 상황이 바뀌어 이유가 맞지 않으면 규칙을 고치세요.
실제 값은 `launcher/App.xaml`에 있고, 화면에서는 그 이름(키)만 씁니다.

## 큰 방향

참고한 디자인은 **파스텔 색 카드를 벤토(도시락) 모양으로 놓고, 그 위에 흰 작은 카드를 띄우는** 스타일입니다.

- **부드럽고 친근하게.** 모드 런처는 게임 파일을 건드리는 무서운 도구로 보이기 쉽습니다. 둥근 모서리와 옅은 색으로 겁을 덜어 줍니다.
- **진한 색은 하나만.** 청록(`Teal`)만 진합니다. 화면에서 진한 색이 보이면 "여기를 누르면 된다"는 뜻입니다.
- **색은 영역의 뜻.** 같은 종류의 정보는 어느 화면에서든 같은 색 카드에 둡니다.

## 색

| 이름 | 어디에 | 왜 |
|---|---|---|
| 배경 `Bg` (아주 옅은 보라 흰색) | 창 바탕 | 순백보다 눈이 편하고, 흰 작은 카드가 떠 보입니다. |
| 글 `Ink` (보랏빛 검정) | 제목·본문 | 새까만 색보다 파스텔과 잘 어울립니다. 어떤 카드 위에서도 아주 잘 읽힙니다. |
| 설명 글 `Sub` (회보라) | 설명 | 본문보다 한 단계 덜 눈에 띄게. 가장 어두운 카드(보라) 위에서도 읽기 기준(4.5:1)을 넘습니다. |
| 청록 `Teal` | 주 버튼, 켜진 스위치, 슬라이더 | 유일한 진한 색 = 누를 곳. 흰 글씨와 대비가 7:1이라 잘 보입니다. |
| 분홍·파랑·보라·초록·민트 | 큰 카드 | 영역을 색으로 나눕니다. **단색**인 이유: 처음엔 그라디언트였는데, 위치마다 글 대비가 달라지고 산만해서 단색으로 바꿨습니다. |
| 경고 글 (적갈색) | "로더와 맞지 않음" 같은 경고 | **흰 카드 위에서만** 씁니다. 보라 카드 위에서는 대비가 모자랍니다. |

카드 색의 뜻:

- **분홍** = 소개·정보 (게임 정보, 설정의 정보)
- **파랑** = 게임·런처 자체의 동작 (게임 실행, 업데이트)
- **보라** = 설치할 내용물 (모드, 애드온 모음)
- **초록** = 모드 로더
- **민트** = 설정 값 (설정 창)
- 라이브러리 게임 카드는 다섯 색을 돌아가며 써서 서로 구분만 합니다.

## 모양

- **큰 카드는 모서리 24**, 그 안의 **흰 줄은 14**, **버튼은 12**입니다. 안쪽으로 갈수록 작게 해야 모서리가 서로 겹쳐 보이지 않습니다.
- **켬/끔 버튼은 10.** 알약처럼 완전히 둥글지 않고 "살짝 둥근 버튼"으로, 안에 "활성화/비활성화"를 글로 씁니다. 체크박스보다 상태가 한눈에 보입니다.
- **알약(완전히 둥근 것)** 은 태그·선택지·아이콘 버튼입니다. 큰 동작 버튼과 모양으로 구별됩니다.
- **그림자는 한 가지만** 씁니다. 보랏빛이라 파스텔 위에서 회색 얼룩이 생기지 않습니다. 흰 요소와 누를 수 있는 게임 카드에만 줍니다.
- **게임 카드는 마우스를 올리면 살짝 떠오릅니다.** 누를 수 있다는 신호입니다.

## 글꼴

- Windows 11의 `Segoe UI Variable`을 먼저 쓰고, 없으면(Windows 10) `Segoe UI`, 한글은 `맑은 고딕`으로 자동으로 넘어갑니다.
- 작은 한글이 흐리지 않게 화면 맞춤 글자 렌더링을 켭니다.

## 아이콘

- **Lucide** 아이콘을 씁니다. 오픈소스(ISC 라이선스)라 자유롭게 쓸 수 있고, 라이선스 파일을 배포 zip에 함께 넣습니다.
- 선 두께가 고르고 끝이 둥글어 둥근 디자인과 어울립니다.
- 아이콘을 **글꼴이나 특수 문자(▶ ←)로 넣지 않습니다.** Windows 10에 없거나 모양이 다르게 나옵니다. 그림(경로)으로 넣으면 어디서나 같습니다.
- 아이콘만 있는 버튼에는 꼭 마우스를 올리면 나오는 설명(툴팁)을 붙입니다.

## 슬라이더

- 범위가 정해진 숫자 설정(예: 0~240 fps)은 슬라이더로 바꿉니다. 지나온 쪽은 청록, 남은 쪽은 옅은 회보라, 손잡이는 흰 원입니다.
- 옆에 **값 입력칸을 항상 둡니다.** 슬라이더만으로는 정확한 값을 넣기 어렵기 때문입니다.

## 배치

- 상세·설정 화면은 **왼쪽 넓은 칸(주 내용)과 오른쪽 좁은 칸(곁 정보)** 의 벤토 격자입니다. 가장 중요한 모드 목록이 넓은 칸에 갑니다.
- 화면은 창 안에서 바뀝니다. 새 창은 **설정 파일 편집**처럼 저장/취소가 분명해야 할 때만 엽니다.

## 문구

- 쉬운 한국어로, **다음에 무엇을 하면 되는지** 적습니다. ("게임을 한 번 실행하면 설정 파일이 만들어집니다")
- 버튼 이름은 동사입니다. ("설치", "받아서 설치", "업데이트")
- 지우는 동작은 무엇이 지워지는지 확인 창에 보여 줍니다.

## Windows 10

- Windows 11에만 있는 효과(반투명 Mica, 아이콘 글꼴 등)는 쓰지 않습니다.
- 참고로 .NET 10이 공식 지원하는 Windows 10은 기업·IoT용 일부 버전뿐입니다. 일반 Windows 10은 지원이 끝나(2025년 10월) 목록에 없지만, 런처는 실행에 필요한 것을 모두 담아 배포하므로 보통 실행됩니다.

## 움직임

- **모든 전환은 같은 곡선(easeInOutCubic), 0.3초입니다.** 화면이 바뀌는 속도가 다 같아야 하나의 프로그램처럼 느껴집니다. 0.3초는 바뀐 것을 알아챌 만큼 길고, 기다리게 하지 않을 만큼 짧습니다.
- **새 화면은 아래에서 살짝 올라오며 나타납니다.** 어디가 바뀌었는지 눈이 따라갑니다.
- **계속 움직이는 것은 마우스를 올린 곳뿐입니다.** 늘 움직이면 산만하니, 손을 댄 곳만 살아 있게 합니다.
- **진행 중 고리는 일정한 속도로 돕니다.** 기다리는 동안 멈추지 않았다는 표시입니다. 받기·설치처럼 오래 걸리는 일은 반드시 이 덮개와 진행률을 보여 줍니다. 아무 표시가 없으면 사용자는 프로그램이 멈춘 줄 압니다.

## 게임 카드 세 칸

- **표지를 눌러야 나옵니다.** 버튼을 늘 보이면 표지 그림이 가려집니다. 카드에서 마우스를 빼거나 다른 곳을 누르면 사라집니다.
- **위 반은 설정·모드, 아래 반은 플레이입니다.** 가장 자주 누를 플레이를 가장 넓게 둡니다.
- **바탕은 흰색 70%(30% 투명), 마우스를 올리면 85%(15% 투명)입니다.** 표지가 비쳐 어느 게임인지 계속 보이고, 올린 칸만 또렷해집니다.
- **화살표는 그 칸이 데려갈 방향입니다.** 설정은 왼쪽, 모드는 오른쪽. 올리면 커집니다.
- **칸마다 아이콘 움직임이 다릅니다.** 설정은 톱니가 돌고, 모드는 상자가 흔들리고, 플레이는 다이아몬드가 반짝입니다. 무엇을 하는 칸인지 한 번 더 알려 줍니다.

## 모드 패널

- **"추가한 모드"(보라)와 "모드 추가하기"(파랑)를 나눕니다.** 모음에 있는 모드가 저절로 설치되지 않는다는 것을 화면 구조로 보여 줍니다.
- **로더는 초록 알약, 태그는 분홍 알약입니다.** 카드 색의 뜻(초록 = 로더, 분홍 = 소개)을 작은 알약에서도 그대로 씁니다.
- **로더 충돌처럼 화면 전체에 걸린 문제는 맨 위 주황 띠로 알립니다.** 한 줄짜리 빨간 글보다 먼저 눈에 띄어야 하기 때문입니다.

## 언어 선택 화면

- **하얀 화면 가운데 드롭다운 하나와 "다음"만 둡니다.** 이때 할 일은 언어 고르기뿐입니다.
- **드롭다운은 처음에 영어로 "Select language"입니다.** 아직 어떤 언어를 읽을 수 있는지 모르기 때문입니다.
- **언어를 고르면 화면 글이 바로 그 언어로 바뀌고 "다음"이 진해집니다.** 이제 누를 수 있다는 뜻입니다.
