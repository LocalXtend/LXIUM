# LXIUM 런처 디자인 규칙 (AI용)

- 사람용 문서: `../human/design.md` (규칙마다 이유를 더 자세히 적음)
- 원본: `launcher/App.xaml`의 리소스. 화면 XAML에 색·반지름·그림자를 직접 쓰지 않고 아래 키를 씀
- 규칙을 바꾸면 `App.xaml`, 이 문서, 사람용 문서를 같은 커밋에서 고침
- 각 규칙의 "이유"가 지금 상황에 맞지 않으면 규칙을 바꿔도 됨. 이유가 여전히 맞으면 규칙을 지킴

## 1. 색 (토큰)

| 키 | 값 | 쓰임 | 이유 |
|---|---|---|---|
| `Bg` | `#F5F4FA` | 창 배경 | 순백보다 눈이 덜 부시고, 흰 카드(`Inner`)가 떠 보임 |
| `Ink` | `#1E1B2E` | 제목·본문 | 검정보다 부드럽고 파스텔과 어울리는 보랏빛 검정. 모든 카드 위 대비 11:1 이상 |
| `Sub` | `#5E5A72` | 설명·보조 글 | 모든 배경 위 4.5:1 이상 (가장 낮은 `Purple` 위 4.5) |
| `Teal` / `TealHover` | `#2F5F6E` / `#244C59` | 주 동작 버튼, 켜진 스위치, 슬라이더 채움, 선택된 알약 | 화면에서 유일한 진한 색 = "누를 곳". 흰 글 대비 7:1 |
| `Pink` `Green` `Blue` `Purple` `Mint` | `#F9DDEB` `#E1F4D0` `#DCEBFB` `#D8CFFA` `#D3F1DB` | 큰 카드 배경 (단색) | 영역을 색으로 구분. 그라디언트는 글 대비가 위치마다 달라지고 산만해서 단색으로 바꿈 (0.1.1) |
| 경고 글 | `#A1452A` | 호환 경고 (`AddonRow.Compat`) | 흰 `Inner` 위에서만 씀 (6.2:1). `Purple` 위는 4.2:1이라 금지 |
| 상태 알약 | 배경 `#EEEAFD`, 글 `#4A3E8C` | 모드 설치 상태 | 7.6:1, 버튼과 헷갈리지 않는 옅은 색 |

카드 색의 뜻 (같은 뜻이면 같은 색):

| 색 | 뜻 | 쓰는 곳 |
|---|---|---|
| `Pink` | 소개·정보 | 게임 정보, 설정 화면 "정보" |
| `Blue` | 게임·런처 자체 동작 | 게임 폴더·실행, 업데이트 |
| `Purple` | 설치할 내용물 | 모드 목록, 애드온 모음 |
| `Green` | 모드 로더 | 모드 로더 카드 |
| `Mint` | 설정 값 | 설정 창 섹션 |
| 다섯 색 순환 | 구분만 | 라이브러리 게임 카드 (`AlternationIndex` 0~4) |

## 2. 모양

| 키 / 값 | 쓰임 | 이유 |
|---|---|---|
| `Card` 반지름 24, 안쪽 여백 26 | 큰 카드 | 참고 디자인의 부드러운 큰 둥근 카드 |
| `Inner` 반지름 14, 흰 배경, `Shadow` | 카드 안 줄 (항목·정보 행) | 바깥 24 − 여백을 고려한 작은 반지름이라 모서리가 겹쳐 보이지 않음 |
| 버튼 반지름 12 | `Primary` `Ghost` | `Inner`보다 살짝 작아 안에 들어가도 어색하지 않음 |
| `Switch` 반지름 10 | 켬/끔 | 알약(999)과 구별되는 "버튼" 모양. 사용자 요청: 살짝 둥근 버튼 + 활성화/비활성화 글 |
| 알약 반지름 999 | `Pill`, `PillItem`, `IconButton` | 태그·선택지·아이콘 버튼은 동그랗게 = 누르는 큰 동작이 아님을 표시 |
| `Shadow` (흐림 20, 깊이 3, 불투명 0.10, `#4B3F7A`) | 흰 요소, 라이브러리 카드 | 그림자는 하나만. 보랏빛이라 파스텔 위에서 회색 얼룩이 생기지 않음 |
| 간격 20 | 벤토 격자 사이 | 카드 반지름(24)과 비슷해 리듬이 맞음 |

## 3. 글꼴

- `Font` = `Segoe UI Variable Display, Segoe UI, Malgun Gothic`. Windows 11은 Variable, Windows 10은 Segoe UI로 자동 대체, 한글은 맑은 고딕
- 크기: 앱 이름 30 Bold, 카드 제목 `Title` 22 SemiBold, 설명 `Desc` 14 (줄 간격 21), 알약 `PillText` 12 SemiBold, 보조 11~13
- `TextOptions.TextFormattingMode="Display"`, `UseLayoutRounding="True"`: 작은 한글이 흐리지 않게

## 4. 아이콘

- Lucide 1.57.0 (ISC, `launcher/Assets/Lucide-LICENSE.txt`, 배포 zip에 동봉). 24×24 격자, 선 두께 2, 둥근 끝
- `App.xaml`의 `Icon*` Geometry. `<circle>`·`<line>`은 경로로 바꿔 넣음
- 아이콘 글꼴(Segoe Fluent Icons 등)·문자(▶ ←) 금지: Windows 10에 없거나 모양이 다름
- `IconButton`(42×42 원, 아이콘 18) = 아이콘만, 반드시 `ToolTip`. 글이 있는 버튼은 `ContentTemplate="{StaticResource IconText}"` + `Tag`(아이콘 15)
- 새 아이콘: lucide-static에서 같은 버전 SVG의 path를 가져와 `Icon<이름>` Geometry로 추가

## 5. 구성 요소 (`App.xaml` 스타일 키)

| 키 | 대상 | 규칙 |
|---|---|---|
| `Primary` | Button | 화면(카드)마다 주 동작 1~2개만 |
| `Ghost` | Button | 보조 동작 (흰 배경 + 옅은 테두리) |
| `IconButton` | Button | 머리글 등 자주 쓰는 도구. `Tag` = 아이콘 |
| `Plain` | Button | 카드 전체를 누르는 영역. 마우스를 올리면 4px 위로 |
| `Switch` | CheckBox | 참/거짓 설정. 꺼짐 = 흰 바탕·회색 점·"비활성화", 켜짐 = 청록·초록 점·"활성화" |
| `SoftSlider` | Slider | 범위가 있는 숫자. 지난 쪽 청록, 남은 쪽 `#E2DFEC`, 흰 원 손잡이. 옆에 값 입력칸을 항상 둠 |
| `PillItem` | ListBoxItem | 하나 고르는 선택지 (로더) |
| `Card` `Inner` `Pill` | Border | 위 모양 표 |

## 6. 배치

- 머리글: 왼쪽 앱 이름 + 부제(지금 화면 이름), 오른쪽 동작 버튼. 페이지마다 보이는 버튼만 다름 (`MainWindow.ShowPage`)
- 상세·설정 화면 = 벤토 격자 `5* | 20 | 3*`. 왼쪽 넓은 칸 = 주 내용(게임 정보, 모드), 오른쪽 = 곁 정보(게임 폴더, 로더)
- 라이브러리 = 236 폭 카드 `WrapPanel`, 세로 표지(Steam `library_600x900`) 208×312
- 화면 전환은 창 안에서 (새 창 금지). 예외: 설정 파일 편집 = 모달 창 (저장/취소가 분명해야 함)

## 7. 글 (문구)

- 쉬운 한국어, 사용자가 다음에 할 일을 적음 ("게임을 한 번 실행하면 만들어집니다")
- 버튼 = 동사 ("설치", "받아서 설치", "업데이트", "재설치")
- 오류는 무엇이 안 됐는지 + 흔한 원인 ("게임이 실행 중이면 끄고 다시 시도하세요")
- 위험한 동작(로더 제거, 모음 추가)은 지워지는 것·위험을 확인 창에 적음

## 8. Windows 10 호환

- Windows 11 전용 기능 금지: Mica/Acrylic, 둥근 창 모서리 API, Segoe Fluent Icons, Segoe UI Variable만 지정
- 새 스타일은 기본 WPF 템플릿 위에서 만들고 OS 테마에 기대지 않음
- 참고: .NET 10 공식 지원 목록의 Windows 10은 LTSC/IoT(21H2, 1809, 1607)만. 일반 Windows 10 22H2는 지원 종료(2025-10)로 목록에 없지만 자체 포함 빌드는 보통 실행됨
